# AI Assistant 🤖

Building my own AI assistant while learning AI Engineering.

## Tech Stack
- Python
- Ollama
- Qwen3:4b

## Progress
- Day 01: Built my first basic AI assistant using Python and Ollama.

- Day 02: Added environment variables using .env to avoid hardcoding configuration values and implemented a while loop for
          continuous conversation with an exit condition.

- Day 03: Added conversation memory by storing user and assistant messages in a list, allowing the AI to use
          previous messages as context.

- Day 4: Added a system prompt to define my AI assistant's personality, behavior, and response constraints. Learned the five ingredients of effective prompting: role, audience, task, constraints, and output format. 

- Day 5: Implemented tool calling (function calling), connecting LLM responses to Python functions using tool schemas, function mappings, and tool results.

- Day 6: Added a weather tool that accepts city arguments, learned argument extraction through tool calling, and enabled the assistant to choose between multiple tools.

- Day 7: Improved tool calling with a multi-step execution loop, added a user-city tool, and handled chained tool calls with step limits and error handling.

## Goal
To gradually make my AI assistant more advanced as I learn new concepts.
